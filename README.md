# 파리에서 로마까지

2026.12.28 ~ 2027.1.9 유럽 신혼여행(파리, 베네치아, 피렌체, 로마) 일정 페이지입니다. GitHub Pages로 공개합니다.

## 구성

- `index.html` — 일정 페이지 (본문, 스타일, 스크립트 모두 포함)
- `img/` — 숙소 위치 지도(`map-*`)와 가볼 만한 곳 지도(`sights-*`). 지도 © OpenStreetMap contributors
- `fonts/` — 페이지에 쓰는 글자만 남긴 Pretendard, Noto Serif KR (SIL Open Font License, 라이선스 파일 포함)
- `sw.js` — 오프라인 저장(서비스 워커). 한 번 연 뒤에는 인터넷이 끊겨도 열립니다.
- `manifest.webmanifest`, `icons/` — 휴대폰 홈 화면에 추가할 때 쓰는 이름과 아이콘

## 고칠 때

- 일정 내용만 바꿀 때는 `index.html`만 고쳐 올리면 됩니다. 인터넷이 되면 항상 새 페이지를 받습니다.
- 그림, 글꼴, 아이콘을 바꾸거나 추가하면 `sw.js`의 `VERSION`을 올리고, 새 파일은 `ASSETS` 목록에도 넣습니다.
- 페이지에 새 한글이 많이 늘면 글꼴 파일에 없는 글자는 기본 글꼴로 보일 수 있습니다. 자주 쓰는 한글 2,350자는 들어 있습니다.
